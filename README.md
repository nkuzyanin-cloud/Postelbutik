# PostelButik · Подбор

Статическая PWA для Windows и iPhone. Реальный пилотный каталог: Luxberry, German Grass, Asabella. Поиск, фильтры, размерные варианты, сравнение, локальная подборка, редактируемый текст предложения, скачивание фото, печать/PDF, импорт/экспорт каталога.

Никаких ИИ API и постоянного прикладного сервера. Публичные файлы находятся в `docs`.

## Загрузка в GitHub Pages

1. Распаковать ZIP. Загрузить СОДЕРЖИМОЕ архива в корень репозитория: папки `docs`, `scripts` и остальные файлы. Сам ZIP загружать не нужно.
2. Открыть Settings → Pages. В Source выбрать Deploy from a branch; branch — main; folder — /docs. Нажать Save.
3. После завершения публикации открыть адрес, показанный в Pages. Каталог поддерживает путь репозитория, например /postelbutik-selector/.
4. На iPhone открыть адрес в Safari → Поделиться → На экран «Домой».

Для бесплатного GitHub Pages нужен публичный репозиторий. Опубликованный сайт доступен всем по ссылке; авторизации в этой сборке нет. Клиентские подборки и подтверждения хранятся только на устройстве. При переходе со старого адреса они автоматически не переносятся; импортированный каталог можно перенести через экспорт/импорт.

При следующих обновлениях заменять присланные файлы с сохранением путей. Менять версию кэша в docs/sw.js. Здесь передан полный проект, не частичный патч. Автоматического обновления цен или отправки сообщений нет.

## Данные

Цены — снимок публичных страниц поставщиков на 05.10.2026, а не живой канал. Точный размерный вариант проверяется перед включением цены в сообщение. Наличие требует проверки. Черновики хранятся только в браузере устройства, не синхронизируются. Фото принадлежат соответствующим брендам; источники записаны в каталоге.

Luxberry: цены из radio-полей размерных вариантов, не из отличающегося JSON-LD. German Grass: данные вариантов из встроенного Nuxt-состояния; неизвестный остаток не объявляется наличием. Asabella: одиннадцать вручную проверенных карточек через публичный веб-источник; прямые запросы ограничены, автоматического обновления нет. Несоответствия наличия сохранены как предупреждения.

## Локальная проверка

`node scripts/verify.mjs`

`node --check docs/app.js`

`node --check docs/sw.js`

Для локального просмотра можно обслуживать `docs` обычным статическим HTTP-сервером. Для установки PWA вне localhost нужен HTTPS.

## Обновление каталога

1. Убедиться, что получение данных по выбранным публичным URL допустимо и доступно. Не обходить 403, авторизацию или ограничения источников.
2. `python scripts/collect_catalog.py` — обновить Luxberry.
3. `python scripts/collect_catalog.py --grass` — обновить German Grass.
4. Обновить вручную записи Asabella в `scripts/prepare_catalog.py`, включая время проверки, цены и статус источника. Не считать поисковую копию страницы текущим остатком.
5. Изменить даты проверки в сборщиках и дату версии каталога. `python scripts/prepare_catalog.py` — подготовить JSON и фотографии.
6. Запустить проверки. При изменении приложения или каталога обновить имя кэша в `docs/sw.js`, затем загрузить изменённые файлы в GitHub. Проверить, что обновлённая версия приходит на устройство.

Список проверенных URL — `sources.json`. Кэш исходных страниц временный, в `.supplier-cache`; перед новым сбором удалить относящиеся к нему старые копии. Старый рабочий каталог при неудаче не публиковать заменённым частичным набором без проверки. Кнопка импорта в приложении принимает экспортируемый JSON формата `schemaVersion: 1`.

## Границы

Не весь ассортимент поставщиков и не все 550 источников. Разбор свободного запроса ограничен правилами и требует проверки параметров. Фото интерьера не анализируется. Отправка сообщений выполняется менеджером. Сохранение печатной подборки в PDF зависит от меню печати устройства. Клиентский текст можно редактировать; при ручном редактировании последующая смена подтверждений не переписывает текст автоматически — приложение предупреждает о необходимости обновить его.

Автоматические проверки покрывают данные, фильтры, комплектацию, цены и импорт. В этой среде браузерная визуальная проверка и проверка на физическом iPhone недоступны; не выдавать их за выполненные.

Подтверждения цены и наличия действуют только в день проверки. WebMCP добавлен с проверкой доступности API; поддерживаемый браузерный контекст для его проверки здесь недоступен.

Расширение 05.10.2026: дополнительные страницы категории Luxberry; модели и размерные карточки German Grass; 11 комплектов Asabella. Дубли размерных SKU объединяются. Противоречивые Asabella 1645-OMP (цвет) и 2148-OMP (число одеял) исключены из расширения до уточнения.

Фотографии расширенного каталога кэшируются по мере просмотра, а не скачиваются все сразу при установке. Офлайн доступны характеристики всего каталога и уже открытые фотографии. При новой версии кэша открытая страница перезагружается после сохранения ранее выполненных действий в localStorage.

При расширении German Grass ограничил частоту запросов (HTTP 429). Сбор остановлен без повторов; 13 страниц не получены. Список записан в `grass-errors.json`. Сборщик теперь прекращает дальнейшие запросы к источнику после 429; максимум два одновременных запроса к карточкам.

Проверенная расширенная сборка: 94 моделей, 224 размерных вариантов.
